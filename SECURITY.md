# Security

Report suspected vulnerabilities privately to the repository owner using
[GitHub private vulnerability reporting](https://github.com/Digvijay-x1/Fluidframe/security/advisories/new)
when available. If unavailable, contact the owner through the contact details on
[their GitHub profile](https://github.com/Digvijay-x1). Do not put credentials or
exploitable details in a public issue.

See [the security controls guide](docs/security.md) for CI checks, vulnerability
thresholds, exceptions, repository settings, and credential rotation.
